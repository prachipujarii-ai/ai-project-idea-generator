## Project Structure
- `start.py` → Entry point for the Streamlit app
- `requirements.txt` → Python dependencies
- `ideas.db` → Local database storing project ideas
- `ui.html` → HTML template for the interface
- `script.js` → JavaScript for interactivity (UI cards, animations)
- `styles.css` → CSS for styling and layout
- `.gitignore` → Keeps unnecessary files out of version control
- `README.md` → Documentation
